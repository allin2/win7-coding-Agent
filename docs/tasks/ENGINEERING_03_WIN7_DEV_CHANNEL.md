### 5.2 命令

| 命令 | 动作 |
|---|---|
| `status` | 只读：主机名、build、agent 会话、开发根占用、开发根进程、`A9-DEV-` 任务、磁盘余量 |
| `put <本地> <远端相对路径>` | SFTP 上传到开发根 |
| `get <远端相对路径> <本地相对路径>` | SFTP 下载到 `outputs/win7-dev/`，下载后做秘密扫描 |
| `ps <脚本文件>` | 以管理 SSH 账户执行 PowerShell 2.0 脚本 |
| `agent-run <名称> <命令行> --wait <秒>` | 以 agent 用户在其交互桌面运行；注册 `A9-DEV-<名称>` 任务，等待结束，读退出码，删除任务 |
| `cand <ZIP>` | 按 ZIP 的 SHA 存到 `C:\A9-DEV\cand\<SHA 前 16 位>\`，目标机复算 SHA 后解包；已存在则复用 |
| `stop` | 结束映像路径在开发根下的进程树，删除全部 `A9-DEV-` 任务 |
| `close` | 先 `stop`，再删除整个开发根；正式门 A 前必须执行 |

### 5.3 设计规则

1. **复用已在 Win7 跑通的载体。** SSH 参数与 `run-rehearsal.cjs` 的 `SSH_OPTIONS` 相同。PowerShell 经 `-Command -` 读标准输入，输入以空行结尾（§11.8.16 教训）。任务 XML 沿用 `admin-materials.ps1` 写法：ASCII、LF、无声明、`InteractiveToken`、`LeastPrivilege`。
2. **路径限定。** 远端路径一律解析到 `C:\A9-DEV\` 之下，越界即拒绝。
3. **进程判据。** `stop` 只按映像路径前缀 `C:\A9-DEV\` 选进程，不做 PID、创建时间、属主三重核对。
4. **超时。** 单次动作默认 600 秒。上传上限按 0.2 MB/s 计算，且不少于 600 秒。
5. **单写者。** 远端 `C:\A9-DEV\LOCK` 记持有者与 UTC。另一会话见锁即拒绝，负责人可要求强制接管。
6. **秘密扫描。** `get` 下载的文本按固定模式扫描（`sk-` 前缀密钥、`Authorization`、`api_key`、`password`）。命中的文件移入 `outputs/win7-dev/quarantine/`，不进入任何文档。
7. **失败也取证。** 每条命令失败时，原始 stdout、stderr、退出码照常落盘。

### 5.4 开发机检查

只做主路径单元测试：参数解析、路径越界拒绝、账本写入、秘密扫描命中。
不做变异测试，不做多路静态审核。工具是否可用以 Win7 自检为准（§9）。
