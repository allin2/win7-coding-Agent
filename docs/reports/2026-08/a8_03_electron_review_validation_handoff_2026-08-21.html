锁定输入

  • 目标运行时：Electron 22.3.27 / Node 16.17.1 / x64。
  • 目标系统：Windows 7 SP1 x64；Win10 为中间验收层。
  • 执行器：src/shell/tests/product/run-electron-review-smoke.mjs。
  • 完整源文件 SHA-256：机器可读验证包。

隔离与副作用

  • 每次执行创建唯一临时工作区和 Electron user-data。
  • 只操作夹具目录；不修改真实项目、注册表、服务、PATH、网络或系统策略。
  • PASS 后自动清理临时目录；FAIL 时保留现场供诊断。
  • 项目测试 Profile 未登记，必须诚实显示 NOT_RUN。

Windows 精确命令

从候选仓库根目录执行；包含空格的参数必须整体加引号。报告与截图目录可预先存在，也可由执行器创建。

node src\shell\tests\product\run-electron-review-smoke.mjs ^
  "--electron=C:\locked-runtime\electron.exe" ^
  "--product=C:\candidate\src\shell\product" ^
  "--report=C:\evidence\a8-03-electron-review.json" ^
  "--screenshot=C:\evidence\a8-03-electron-review.png"

开发机替代运行使用同一参数合同；非 Electron 22 的结果只属于 DEVELOPER_SURROGATE_ELECTRON，不能作为 Windows 目标 Gate。

自动核验

  1. Electron 退出码必须为 0。
  2. 报告顶层与 8 个 case 都必须为 PASS。
  3. 外层执行器独立复算 9 个产品文件 SHA-256，并与报告逐项比较。
  4. PNG 必须存在且大于 1024 bytes。

失败处置

  1. 保持 FAIL / NOT_PERFORMED 原值，不手工改报告。
  2. 保存 JSON、PNG、stdout、stderr 和打印的临时目录。
  3. 核对报告 artifact_hashes 与机器可读验证包；不一致即候选漂移。
  4. 修复后形成新哈希和新记录，不覆盖旧证据。
