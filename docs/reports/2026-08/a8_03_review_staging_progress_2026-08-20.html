4. 安全与副作用边界

Review/decision 阶段零工作区写入：Replay 只调用结构化 workspace.review_prepare；Host 将字节放入按任务隔离的私有 staging。接受/拒绝只改变 ReviewSet 事实，正式工作区只有在精确 approval 通过、全量预检成功后才进入 Apply。

边界本轮事实没有宣称
凭据Host 只把已知值作为 tainted bytes 交给 staging scanner；Review public DTO 不带 blob 内容。未知秘密的完备识别。
验证PASS 必须 trustedAdapter + complete + non-truncated + profileId；模型文字不能升级为 PASS。真实项目测试 PASS。
恢复回滚不确定写 recovery manifest，状态为 RECOVERY_REQUIRED，后续写入锁定。A8-05 重启后完整恢复。
RendererPreload 暴露 Review 专用方法，IPC 拒绝未知 action/字段/hash；Chromium DOM Harness 已覆盖完整 UI journey。真实 Electron Preload/IPC 越权与视觉 Gate。
