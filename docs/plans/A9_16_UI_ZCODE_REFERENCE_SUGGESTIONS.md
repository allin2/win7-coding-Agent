## 2. ZCode 截图观察清单（可参照模式盘点）

1. **左栏三段式**：顶部固定全局入口（新建任务 ⌘N、搜索 ⌘K、自动化、插件市场）→ 分组/项目
   切换 chips + 折叠/归档小工具 → 剩余全部高度给会话列表，独立滚动。
2. **会话列表组织**：按项目分组、组头可折叠；行内"标题 + 相对时间"（刚刚 / 3分 / 4小时 / 13天）；
   组尾"显示更多"承接分页；当前项高亮。
3. **双开关**：左上折叠侧栏、右上开关右侧面板，均为图标按钮 + 状态；
   主区标题栏带工作区与分支 pill。
4. **主内容流**：用户消息右侧 pill；Agent 轮次内嵌可折叠块——"思考 · 持续了几秒"（ collapsed 思考）、
   "终端 + 行内命令"（工具卡）、"查阅 · 1 搜索, 1 文件"（结果摘要行）、"已停止"状态行。
5. **Composer 单行紧凑**：模式 pill（完全访问 + 盾形图标）、模型选择、强度选择、附件、发送。

## 3. 优化建议（逐条映射 A9-16）

### A. 左侧对话区（重点，对应截图红框；U01/U02）

| # | 现状 | ZCode 参照 | 建议 | 需求对应 |
|---|---|---|---|---|
| A-1 | 对话列表与导航/归档/信任注记/底部按钮同栏纵向竞争 | 全局入口固定在顶，列表独占剩余高度 | 左栏改为三段式：固定全局区（新建对话/搜索入口）→ 可折叠辅助区（归档、信任注记默认折叠为图标行）→ 列表 `flex:1` 独立滚动；底部操作并入列表区顶部或全局区 | U01 |
| A-2 | 行高 42px×2 行文本，232px 宽下长标题截断不可控 | 行内"标题 + 相对时间"，单行主标题 | 重算预算：768 − 标题栏 − 全局区（≤2 项）− 分组头 ≥ 4×行高 + 间隙；建议行高压到 36–40px、时间改右对齐单行 | U02 |
| A-3 | 列表平铺，仅"当前/归档"两级 | 分组头 + 相对时间 + "显示更多" | 引入"进行中 / 更早"两个动态分组（单工作区产品不引入多项目分组），组头可折叠且 `aria-expanded`；"加载更早"沿用既有分页游标作为组尾入口 | U01/U02 |
| A-4 | 无列表内搜索 | ⌘K 全局搜索 | 本轮只做列表内过滤输入框（纯前端过滤已有 DOM 分页页），全局搜索不进 A9-16 范围 | 超范围，记录不做 |

## 4. 明确不参照的 ZCode 特性（A9-16 §6 非目标）

自动化、插件市场、多项目/多工作区分组、⌘K 全局搜索、token 级模型流式输出、多窗口、
交互式终端与 stdin 注入。截图中的这些元素只作视觉语言参考，不进入需求或实现范围。

## 5. 实施授权前需负责人定案的设计决定

- D1 会话行密度：单行标题+右对齐时间（ZCode 式，密度高）vs 现状双行（信息多）。建议前者。
- D2 分组模型："进行中/更早"两分组 + 归档折叠（建议），或维持平铺仅提密度。
- D3 侧栏/Inspector 开关状态是否跨重启持久化。任务书明确留白；建议 alpha.2 首轮不持久化。
- D4 桌面态断点：建议 ≥1280px 桌面四态、<1280px 抽屉（1366×768 最低目标机必须为桌面态）。
- D5 运行中输出默认展开/折叠策略（建议运行中展开、结束折叠为摘要行）。
- D6 Review 决定面板归属：Inspector"变更"标签页内嵌（建议）vs 独立弹层。
- D7 若本文件任一建议与 A9-16 任务书条文冲突，以任务书为准并在此登记差异。

## 6. Win7 / Electron 技术约束

- 运行时锁定 Electron 22.3.27 x64（Chromium 108 / Node 16.17.1，`src/shell/package.json:23`、WIN7_CONSTRAINTS D-009）：CSS 能力上界为 Chromium 108（`:has()`、container queries 可用但不建议依赖，布局状态一律由 JS 状态类驱动，与 aria 同源）；
- 禁止 Windows 10+ 专属 API 与未登记组件；DPI 变化用既有 CSS 媒体查询路径，不引入新原生依赖；
- 中文文本、长路径、CR/LF 与跨 chunk UTF-8 边界是 U07/S04 的一等验收项；
- 所有新交互控件需键盘可达（焦点序、可见焦点样式、`aria-*` 同步），沿用现版 `icon-button`/`nav-item` 模式。

## 7. 建议验收对照（与 U07 对齐）

| 维度 | 取值 |
|---|---|
| 分辨率 × DPI | 1366×768 × 100%、1366×768 × 125%、更矮窗口抽样 |
| 布局四态 | 双开 / 仅左 / 仅右 / 双关，各态断言：无横向滚动、主区取宽、审批卡与输入框可达 |
| 列表密度 | 默认工作台无遮挡时 ≥4 条完整对话行可见且可滚动 |
| 键盘 | Tab 焦点序覆盖全局区→列表→主区→Composer；开关按钮 aria-expanded 与视觉一致 |
| 内容压力 | 中文长标题、长路径、错误条、Review 卡、高影响确认卡均不截断关键操作 |
