03 / Execution model

先读，后计划；先批准，再动手

v1 采用 Plan/Apply 双阶段。它不依赖交互式控制台，也不会让模型在执行中悄悄扩大文件或命令范围。

01 · DISCOVER只读发现工作区、能力和项目规则。
02 · PLAN模型生成确切 ChangeSet、命令别名和验证策略。
03 · REVIEW写出 JSON 计划、补丁预览和计划 SHA-256。
04 · APPROVE用户用计划文件与哈希显式启动 Apply。
05 · APPLY预检、备份、原子替换、命令和验证。
06 · AUDIT完成、回滚或 REPLAN_REQUIRED，全链路留痕。
最重要的安全性质 Apply 只能消费已批准的路径、base hash、变更和命令别名。 任何新需求都必须停止并重新规划。
为什么不直接做“完全自主修改” Win7 与 Python 3.8 均已 EOL；本地状态、源码和测试环境又具有实际破坏力。 第一版应优先做到可证明安全，再决定是否引入可恢复的动态审批状态。
04 / Modules

只有五个地方能接触真实世界

模块真实边界不可绕过的规则
workspace/ 路径、realpath、NTFS 工作区 词法 + 实路径双校验；中文、空格和 260 限制
gateway/ 唯一允许的网络 endpoint HTTPS、CA、无重定向、请求/响应上限
fs/ 文件读写 base hash、备份、同目录临时文件、os.replace、回滚
runner/ 子进程 命令别名、argv-only、stdin 关闭、超时、截断、树终止
storage/ SQLite 与 artifacts 版本、事务、完整前缀、敏感内容最小化 
cli
  └─ application/runtime
       ├─ context
       ├─ gateway ── models
       ├─ policy
       ├─ tool registry ── workspace / fs / runner
       ├─ verification
       └─ storage / audit

禁止：业务模块直接网络、直接 Popen、直接写文件。
05 / Gateway contract

协议要窄，错误要诚实

Transport HTTPS + JSON

http.client / ssl；显式 CA；独立连接、读取与总时限。

Versioning protocol_version = 1

不支持的版本和缺失必填字段在建立模型回合前拒绝。

Retry request_id 幂等

只重试未获得有效响应的请求；服务端按 request_id 去重。

v1 刻意不做

不做流式响应、Cookie、重定向、任意 URL、客户端模型厂商适配， 也不在证书失败时提供“自动忽略”按钮。

数据最小化

客户端只发送模型为当前任务请求且 Policy 允许的片段；默认拒绝凭据、 私钥和环境文件。出站审计记录相对路径、字节数和哈希，不在普通日志复制完整源码。

06 / Permission model

模型可以建议，不能授权

权限默认可获得的最宽授权
READ_ONLY允许工作区内、限量、敏感路径除外
WORKSPACE_WRITE拒绝批准计划中的路径 + base hash
PROCESS_EXECUTION拒绝批准计划中的命令别名 + 预算
GATEWAY_NETWORK配置控制唯一 scheme / host / port
EXTERNAL_WRITE永久拒绝无
ADMIN_OR_SYSTEM永久拒绝无
DENY 是成功的安全结果 拒绝动作计入预算、写入事件、实现调用次数为 0；Run 可以继续寻找只读替代方案。

命令不是字符串，而是别名

模型只能请求例如 unit_tests 的用户登记别名。 别名冻结 argv、cwd、timeout、输出上限和允许参数；模型不得拼接 cmd /c 或任意 Shell。

07 / Win7 profile

技术选型服从现场，而不是开发机

问题推荐选型原因
产品形态CLI + 薄 .bat无常驻、无管理员、无浏览器依赖
配置INI + JSONconfigparser/json 均为标准库
状态本地 SQLite零部署、事务、已有基线
文件预览difflib unified diff只用于审阅，执行用结构化 ChangeSet
编码BOM → UTF-8 → GBK确定性；歧义即拒绝
进程终止taskkill /T /F → kill不引入未批准 ctypes
交付zip + SHA-256复制即用，不在线安装
升级版本目录并存状态目录独立，易回滚
不能说“兼容 Win7”，只能说“待 Win7 验证” macOS 上的 Python 3.8.10 证据只证明语言级兼容。cmd、CP936、NTFS、 taskkill、SQLite URI 和 winerror 206 必须在 E1/E2 实机核销。

09 / Acceptance

“能运行”必须能被证明

  • Win7 E1/E2 完成只读分析并引用真实路径和行号。
  • 证书错误明确失败，禁止静默关闭校验。
  • Plan 对工作区零写入、零命令执行。
  • 计划哈希或 base hash 不一致一律拒绝。
  • 注入写入故障后恢复所有原文件 SHA-256。
  • 未批准动作的实现调用次数为 0。
  • 超时进程树被终止或明确标记降级。
  • Git 缺失不影响核心 Agent。
  • 审计能重建完整操作顺序。
  • 控制台输出逐字节 ASCII。
  • 全代码通过 CPython 3.8.10 compileall。
  • 复制交付包后无需在线安装。
