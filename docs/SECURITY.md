# SECURITY — 威胁模型与安全规则

## 1. 安全定位

Win7 端 Agent 是一个**可以修改文件、执行命令的本地程序**，其最大风险来源是：
(a) 远程模型输出的指令不可信；(b) 运行环境（Win7 + Python 3.8.10）均已 EOL，无官方安全补丁。
因此安全策略以**限权、留痕、可回滚**为核心，而不是依赖平台自身的安全性。

## 2. 威胁模型

| 威胁 | 场景 | 对策（落实阶段） |
|------|------|------------------|
| T1 模型指令越权写文件 | 模型要求修改工作区外文件（系统目录、其他项目） | 工作区边界强制校验，越界写一律拒绝并审计（阶段 4/6） |
| T2 模型指令执行危险命令 | `format`、`del /s`、注册表修改等 | 命令白名单/确认模型（阶段 6）；本项目自身代码禁止生成此类命令 |
| T3 子进程失控 | 死循环、fork 炸弹式子进程、超大输出耗尽磁盘/内存 | 超时 + 输出字节上限 + 进程树终止（AGENTS.md C08；阶段 2） |
| T4 敏感信息外泄 | 源码/凭据被发送到远程模型服务器 | 仅内网服务器；传输内容审计留痕（阶段 3/5）；不采集与任务无关的文件 |
| T5 传输被窃听/篡改 | 内网 HTTP 明文 | 优先 HTTPS + 证书校验；**禁止静默禁用证书校验**；证书不可用时明确报错（阶段 3，Model Gateway） |
| T6 交付包被篡改 | U 盘/共享盘分发途中被替换 | 交付包哈希清单 + 安装时自校验（阶段 7） |
| T7 审计被绕过 | 直接调用底层 API 绕过工具层 | 代码规范：业务代码禁止直接 `subprocess`/裸写文件（AGENTS.md §6），静态扫描把关 |

## 3. 对当前阶段（0/1）生效的安全规则

阶段 1 的 Capability Probe 虽然只读环境信息，但仍必须遵守：

1. **零网络**：Probe 不发起任何网络连接。TLS 探测（Python TLS Runtime Capability）仅检查本地 `ssl` 模块能力与证书库数量统计，不连接任何主机、不访问公网、不验证企业代理、不做 SChannel 网络握手（ADR-0016）。
2. **零系统改动**：不写注册表（允许的例外：按 D-008 **只读** `HKLM\...\CurrentVersion` 版本信息，不属于改动）、不改环境变量、不在测试目录以外创建文件；所有临时文件在退出时清理（清理失败记入报告，不静默）。
3. **不采集敏感信息**：报告中不得包含环境变量全量 dump、用户文件列表、网络配置详情、**证书完整内容**（只允许证书数量等统计值）；用户名仅记录账户名本身。
4. **子进程安全**：Probe 自身启动的探测子进程同样受超时/截断/终止约束，且只允许调用固定白名单：`python.exe`（sys.executable）、`cmd.exe /c`、`taskkill.exe`、`tasklist.exe`、`git.exe`（仅 `--version`）。
5. **报告完整性**：JSON 报告写入采用"临时文件 + 原子改名"方式，避免半截文件被误当有效报告。

## 4. EOL 平台风险声明（必须让使用方知情）

- Windows 7 与 Python 3.8 均已停止安全维护，本项目**无法**修复平台层漏洞。
- 缓解措施：默认离线运行；网络能力仅限内网、默认关闭；Agent 进程不监听任何端口。
- 该风险必须写入交付说明，由部署方确认接受。

## 5. 凭据管理（阶段 3 前冻结）

- 远程模型服务器凭据（若有）以本地文件存放，路径由用户指定，文件内容不入审计日志、不入 SQLite、不入 JSON 报告。
- 代码与文档中禁止出现任何真实凭据样例。

## 6. 安全相关的开发纪律

- 所有异常路径必须留痕：捕获 → 结构化记录 → 决定降级或中止，禁止 `except: pass`。
- 删除/覆盖类操作前必须先备份（阶段 4 落实）；Probe 阶段只允许删除自己创建的文件。
- 每个阶段验收含安全项抽查（见 EVALUATION.md §4）。
