# PROJECT_CHARTER — 项目章程

## 1. 背景与动机

存量工业/办公环境中仍有大量 Windows 7 SP1 x64 机器无法升级（合规、驱动、专用软件绑定）。
主流 Coding Agent（依赖 Node.js/Electron/新版 Python/联网安装）无法在这些机器上运行。
本项目提供一个**只依赖 Python 3.8.10 标准库、完全离线交付**的 Agent 执行端，把模型推理放到远程/内网服务器，Win7 端只做确定性的本地操作。

## 2. 项目目标（最终态）

Win7 端进程具备以下能力（分阶段交付，见 `docs/ROADMAP.md`）：

1. 环境能力探测与自检（阶段 1）。
2. 代码读取：文件树遍历、按编码正确读文件、基础代码检索。
3. 受控修改：补丁式写入、写前备份、可回滚。
4. 非交互式命令执行：带超时、输出上限、进程树终止。
5. 测试验证：运行项目测试命令并结构化收集结果。
6. 状态保存：任务状态、操作历史持久化到 SQLite。
7. 审计：所有文件修改与命令执行留痕，可导出。
8. 与远程模型服务器的通信协议客户端（内网 HTTP/HTTPS）。

## 3. 当前范围（阶段 0 + 阶段 1）

**做**：
- 建立文档体系、约束体系、决策记录机制（阶段 0）。
- 完成 Capability Probe 的完整设计文档（阶段 1 设计部分，已完成并获批 APPROVED_FOR_IMPLEMENTATION）。
- 阶段 1 实现：仅限任务文档允许路径内（AGENTS.md C14 / ADR-0011）；可在现代开发环境 + Python 3.8.10 上开始，完成标记以 E1/E2 验收为硬门槛。

**不做（当前明确的非目标）**：
- 不实现 Agent Loop 或任何任务编排。
- 不接入任何大模型（本地或远程）。
- 不修改用户代码，不实现写入/补丁能力。
- 不实现网络通信协议（含真实 TLS 握手，留待阶段 3 Model Gateway）。
- 不在阶段 1 允许路径之外编写任何实现代码。
- 不做 GUI；最终形态也仅为 CLI。

## 6. 关键风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| Python 3.8.10 已 EOL，无安全更新 | 安全漏洞无法通过升级修复 | 记入 SECURITY.md；限制网络面；离线运行为主 |
| Win7 系统 CA 证书库陈旧 | HTTPS 校验失败 | 阶段 1 探测证书能力（仅数量统计）；阶段 3（Model Gateway）评审自带 CA bundle（D-006） |
| 无 Win7 实机做持续验证 | 兼容性回归无法发现 | 允许在现代环境开发回归（E3）；但 E1/E2 验收是阶段完成硬门槛（EVALUATION.md） |
| 子进程超时后 Windows 上无法杀干净进程树 | 僵尸进程、句柄泄漏 | 阶段 1 即探测 `taskkill /T /F` 可用性（见 ADR-0005） |
| cmd 控制台 CP936 编码 | 非 ASCII 输出乱码/UnicodeEncodeError | 控制台仅 ASCII，详情写 UTF-8 文件（AGENTS.md §6） |

## 7. 交付形态

- 交付物为一个目录（可 zip 打包），包含文档 + （未来）纯标准库 Python 包。
- 安装方式：复制到任意本地路径（含中文/空格路径）即可运行；不写注册表、不需管理员权限。
